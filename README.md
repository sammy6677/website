# Fasmie – Phone Cases Website

A simple one-page advertising website for **Fasmie**, a phone case shop in Nairobi, Kenya: cases for iPhone and Samsung, plus accessories.

- **67 phone cases with photos, KSh 500 each**, filter by iPhone/Samsung or search by phone model
- What we sell, how to order, and where to buy (in person, TikTok Live, Jumia, Kilimall)
- "Order on WhatsApp" buttons that open a chat with a ready-made message
- Works on phones and computers, with light and dark mode
- One file (`index.html`): plain HTML and CSS, nothing to install

Live site: https://sammy6677.github.io/website/
